# last30days — 近期舆情研究工具，8 源 + 互动量聚合（深度 + 成品）

研究 skill（本会话内置，已 8 源 Ready）：专做"最近 30 天大家在说什么"。从 Reddit、X、YouTube、TikTok、Hacker News、Polymarket、GitHub、web 拉帖子**及互动量/engagement**，按话题聚合（上次跑 "AI news releases funding controversy" 出 55 条）。

**关键差异（对比 agent-reach）**：源少一半，但把**近期(30天窗口) + 互动信号 + 话题聚合**焊死在流水线里，开箱即用直接产出"大家怎么看"。基本零配。定位是**上层研究成品**，不是取数原语。

**对本项目的关系（external-signal）**：若选题 skill 需要**现成的近期舆情/热度信号**来验证"这个选题现在有没有人聊、热度如何"，用它比 agent-reach 省事。同样补的是"选题的外部验证"，不是从对话 session 提炼选题本身。
