# immortal-skill — distills from chat logs, but the output is a persona profile rather than a topic

An open-source digital-clone / memory-distillation skill that supports collecting from **external chat logs** such as WeChat, Feishu, iMessage, Telegram, etc., and distilling a persona profile (digital clone) per the OpenClaw Soul Spec, with a complete Chinese README (~699⭐).

**Relationship to this project (a mismatched reference)**: it proves the path of "distilling a structured artifact from chat logs" is viable, but it is off in two places — ① the source is **external IM chat logs** rather than a conversation session with AI; ② the output is a **persona profile** rather than a post topic. Its value lies in its collection/distillation pipeline serving as a schema-design reference. See the related curated list at [awesome-distill-skills](https://github.com/sdamkkk/awesome-distill-skills).
