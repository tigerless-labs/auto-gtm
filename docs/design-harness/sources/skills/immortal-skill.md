# immortal-skill — 从聊天记录蒸馏，但产出是人格画像而非选题

开源数字分身 / 记忆蒸馏 skill，支持从微信、飞书、iMessage、Telegram 等**外部聊天记录**采集，按 OpenClaw Soul Spec 蒸馏出人格画像（数字分身），中文 README 完整（约 699⭐）。

**与本项目的关系（错位参考）**：它证明了"从聊天记录蒸馏结构化产物"这条路可行，但两处错位——① 来源是**外部 IM 聊天记录**而非和 AI 的对话 session；② 产出是**人格画像**而非 post topic。价值在于它的采集/蒸馏管线可作为 schema 设计参考。相关精选清单见 [awesome-distill-skills](https://github.com/sdamkkk/awesome-distill-skills)。
