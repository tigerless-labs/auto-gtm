# X 选题风格：从 session 沉淀有价值的干货——分享+@作者，或原创反思/见解

目标平台是 **X/Twitter**（非小红书）。核心是"**有价值的干货**"，内容分两类：
- **分享型 + 归因 @**：session 里冒出的工具/产品/人 → 分享它，@ 其作者（本 session 本身就是——对比 Codex/Claude browser use、挖出 content-collector-skill、agent-reach）。
- **反思型 / 原创见解**：从这段探索里提炼出的反思、方法论、有价值的观点（不一定挂在某个工具/人身上，不强制 @；但**有相关帖子/博主能 @ 更好**）。

据此该 skill 要做三件事：
- **实体抽取**：session 里提到的工具/产品/人 → 映射到其 X handle（分享型必做；反思型有相关帖子/博主时也 @）
- **洞察抽取**：这段对话的"干货"是什么——一句能立住的结论、或一个值得说的反思
- **价值闸门**：不是每段 session 都有可发的选题；没有真东西就跳过，不硬凑

（这是人类的产品判断，暂无外部证据支撑；对标的是灵造缺的"从对话沉淀选题"环节，见 [灵造手册](../sources/incumbent/lingzao-manual.md)。）
