# content-writer — draft the post from topic + @ + voice

Part of **skill 2: x-content-generator**.

Responsibilities:
- Write **1-2 post drafts** for the confirmed topic, applying the voice ([tone-learner](tone-learner.md): `tone-examples.md` exemplars + inlined rules) and placing the [at-finder](at-finder.md) @ naturally; **include the source link for shares**
- If the shared thing is already sharp, let it stand — attribution + the thing itself, no bolted-on hot-take
- Judgment step → goes through a **prompt** (no script)

Boundary:
- Produces drafts only; publishing is out of scope (see the [auto-publish-markdown-to-x idea](../../ideas/auto-publish-markdown-to-x.md) for the downstream)

Note: in the shipped skill, voice and drafting are one SKILL step ("Learn the voice and draft"); kept as separate design modules here for the module→file map.

Basis: @ from [at-finder](at-finder.md), voice from [tone-learner](tone-learner.md)
