# content-writer — draft the post from topic + @ + tone notes

Part of **skill 2: x-content-generator**.

Responsibilities:
- Write **1-2 post drafts** for the confirmed topic, following the [tone-learner](tone-learner.md) notes (voice, structure, hook patterns, what comments reward) and placing the [at-finder](at-finder.md) @ naturally
- If tone learning was skipped (external tools not installed), still draft — but mark the draft as not tone-grounded
- Judgment step → goes through a **prompt** (no script)

Boundary:
- Produces drafts only; publishing is out of scope (see the [auto-publish-markdown-to-x idea](../../ideas/auto-publish-markdown-to-x.md) for the downstream)

Basis: @ from [at-finder](at-finder.md), tone notes from [tone-learner](tone-learner.md)
