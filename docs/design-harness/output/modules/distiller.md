# distiller — 从 session 提炼干货：实体 + 洞察

责任：
- **合并三来源**：热点only / session only / 两者重合（[topic-source-independence](../../ideas/topic-source-independence.md)）
- **抽实体**：session 里的工具/产品/人 → 候选 @ 对象
- **抽洞察/反思**：一句立得住的结论，或一个值得说的反思
- 判断性步骤 → 走 **prompt**（非脚本）

边界：
- 只提炼，不生成成品选题（交下游 topic-generator）
- 不做外部取数（交上游 hotspot-fetcher）

依据：[X 选题风格 idea](../../ideas/x-topic-style-ganhuo-at-creators.md)、[content-collector 的 prompt/schema 模式](../../sources/skills/content-collector-skill.md)、[Distill](../../sources/skills/distill.md)
