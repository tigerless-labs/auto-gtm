# x_handle_map — in-session 实体 → X handle 静态表

分享型选题用这张表把**实体名**换成 X **handle** 去 @。高频实体走表（快、省一次搜索），查不到的走 `agent-reach` 搜 X 兜底。

⚠️ **用前必读**：@ 错账号会误 @ 到真实的人，比不 @ 更糟。**只有你有把握的 handle 才写进这张表**；表里没有或不确定的，一律用 `agent-reach` 搜 X 核实，宁可不 @ 也不要猜。下表是种子，按需增补、并定期核对（handle 会变）。

**增补规则**：
- 一行一个实体 → 一个确定的 handle。
- 拿不准的别写；用 `agent-reach` 搜到并确认后再加。
- 个人作者（如某工具的开发者）比组织号更容易变/认错，加之前务必核实。
